Chattahoochee River Temperature Model

Team project · Fall 2025

Overview

My team modeled water temperature in the Chattahoochee River using real U.S. Geological Survey (USGS) data from two monitoring sites: near Buford Dam and near Norcross.

The approach

We used second-order ordinary differential equations to describe how river temperature changes with the seasons. Then we used MATLAB, Mathematica, and Desmos to compare the solution curves with the measured data and develop a best-fit model.

What we found

Comparing the two locations showed how temperature patterns change along the river. We also discussed how a model like ours could help with seasonal prediction and with understanding environmental changes and climate trends.

What I learned

This project taught me how to turn real, messy measurements into a mathematical model, and how to check whether a model actually fits the data. Those skills apply directly to engineering work like monitoring sensors and tuning systems.
